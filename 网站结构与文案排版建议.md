# 网站结构与文案排版建议

## 一、网站整体结构

基于当前的Vue 3 + Vite前端框架和后端内容生成服务，建议采用以下网站结构：

### 1. 页面结构

```
├── 首页 (Home)
├── 文章列表页 (Article List)
│   └── 分类筛选页 (Category Filter)
├── 文章详情页 (Article Detail)
├── 工具包列表页 (Toolkit List)
├── 工具包详情页 (Toolkit Detail)
├── 关于我们 (About)
└── 联系我们 (Contact)
```

### 2. 核心组件

```
├── 顶部导航栏 (Header)
├── 侧边栏 (Sidebar) - 分类导航
├── 内容卡片 (Content Card) - 文章/工具包预览
├── 内容详情 (Content Detail) - 完整文案展示
├── 底部信息栏 (Footer)
└── 搜索组件 (Search)
```

## 三、排版规范与最佳实践

### 1. 文字排版

- **字体选择**：使用系统默认字体栈，确保跨平台一致性
  ```css
  font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  ```

- **字号层级**：
  - 标题：24px - 36px
  - 副标题：18px - 22px
  - 正文：16px
  - 辅助文字：14px
  - 版权信息：12px

- **行高**：
  - 标题：1.2 - 1.3
  - 正文：1.6 - 1.8
  - 列表：1.5

### 2. 颜色方案

- **主色调**：建议使用蓝色系 (#1E88E5)，传达专业和信任感
- **辅助色**：绿色 (#4CAF50) 用于成功状态，红色 (#F44336) 用于警告
- **中性色**：
  - 背景：#F5F5F5
  - 卡片背景：#FFFFFF
  - 文字：#333333 (主)、#666666 (次)、#999999 (辅助)

### 3. 间距规范

- **卡片间距**：16px
- **内容边距**：20px - 30px
- **段落间距**：16px
- **行内元素间距**：8px

### 4. 响应式设计

- **移动端**：单列布局，隐藏侧边栏，使用汉堡菜单
- **平板**：双列布局，可折叠侧边栏
- **桌面端**：三列或多列布局，完整展示所有组件

## 四、实现建议

### 1. 前端组件开发

- 创建 `ContentCard.vue` 组件用于展示文章/工具包预览
- 创建 `ContentDetail.vue` 组件用于展示完整文案
- 使用 Vue Router 实现页面导航
- 使用 axios 与后端 API 交互

### 2. 后端 API 优化

- 添加分页接口，支持大量内容的高效加载
- 添加分类筛选接口，便于用户快速找到感兴趣的内容
- 实现搜索功能，支持按关键词查找内容

### 3. 内容管理

- 利用现有的 `AutoContentPublisher` 类实现每日自动生成新文案
- 建议每天固定时间（如凌晨2点）生成次日的推荐内容
- 为生成的内容添加适当的分类标签，便于用户筛选

import Footer from './components/Footer.vue'
import ContentCard from './components/ContentCard.vue'
import TodayFeature from './components/TodayFeature.vue'
import axios from 'axios'

## 六、总结

以上建议基于当前项目的技术栈和内容生成需求，旨在创建一个结构清晰、排版美观、用户体验良好的垂直生活健康内容平台。通过合理的组件设计和布局规划，可以确保每日生成的新文案得到有效的展示，同时为用户提供便捷的浏览和搜索体验。
